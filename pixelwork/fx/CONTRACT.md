# 特效帧动画包 —— 共享工程约定（所有特效包统一）

特效是**叠加在角色之上的独立图层资源**，不是角色。目标是能直接盖在 32px 怪物/角色上播放。

## 1. 硬性约定（违反就不像素画）

1. `SIZE = 32`（32×32，与怪物世界同尺寸，方便直接叠加）。
2. 有限调色板 ≤ 16 色；索引 0 = `(0,0,0,0)` 透明；其余颜色 alpha 必须 255（**禁止半透明**）。
3. 索引 1 = 描边深色（建议 `(34,30,44,255)`，不要用纯黑）。
4. `fill=` / `outline=` 一律传**调色板索引**，绝不能传 RGB。
5. 只画硬边：放大一律 `Image.Resampling.NEAREST`（模板已处理）。
6. **特效也要描边**：主体色块外一圈索引 1，否则叠在深色或浅色背景上都会糊。
   但 **≤4px 的高光点/火星不描边**（会被吃成黑块），改用亮色直接点。
7. **中心锚点写死**：`CX = 16`、`CY = 16`（特效膨胀/收缩围绕它），
   半径用参数 `r` 控制，绝不逐帧重算中心点坐标，否则播放时会飘。
8. **不截断**：任何一帧的有效像素不得超出 `0..31`；最大半径控制在 14 以内
   （`CX-14=2` 到 `CX+14=30`），留 1px 余量。
9. 帧间必须有真实差异 —— 模板会拒绝重复帧（`IDENTICAL_POSES`）。
   判定标准：相邻帧不能只是整体缩放/平移，必须有**粒子位置或形状结构**的变化。
10. 输出目录必须是全新空目录（模板会拒绝已存在的目录）。

## 2. 图层结构（沿用模板四层，自下而上）

`LAYER_ORDER = ['back', 'body', 'weapon', 'fx']`

| 层 | 特效里放什么 |
|---|---|
| `back` | 最外圈的淡色扩散层（外发光、稀薄烟、冲击波淡环） |
| `body` | 主体（火球、烟团、光球、弧光主体） |
| `weapon` | 中景碎屑 / 飞散粒子 / 火星 / 星芒尖端 |
| `fx` | 最亮高光（白心、亮黄内焰、法阵亮线），面积要小 |

## 3. 姿态参数

在模板 `pose()` 基础上扩展，但**必须统一走 `pose()` 一个入口**：

- `r`：主半径（围绕 CX/CY 膨胀/收缩）
- `dy`：整体上移（烟上升用负值）
- `n`：粒子数量或展开档位
- `hot`：0 正常 / 1 最亮帧（高光色占主体）
- `fade`：0..2 消散档位（2 = 只剩零星粒子）

不同特效可自取参数名，但中心点永远是 `CX/CY`。

## 4. 时间轴编排（先排再写）

| 类型 | 收尾要求 |
|---|---|
| **单发型**（impact / slash / explode / burst） | 逐帧衰减，最后一帧只剩少量残影或零星粒子，**不要完全空白**（空白帧会被图集工具裁掉） |
| **循环型**（smoke / dust / charge） | 末帧必须接近首帧，否则 loop 会跳帧 |

标准节奏：
- 冲击/命中 4 帧：**白闪 → 星芒张开 → 最大 + 碎屑 → 收缩衰减**
- 爆炸 6 帧：**小闪 → 膨胀 → 最大（白心）→ 火焰分裂 → 烟 + 火星 → 烟圈消散**
- 烟雾 6 帧：**小团 → 上升变大 → 翻滚 → 拉长 → 变淡 → 接近消失（循环回首帧）**
- 扬尘 4 帧：**起尘 → 扩散 → 后飘 → 变淡**

## 5. 脚本与输出路径

```
pixelwork/fx/gen_<fx>.py                  # 生成脚本（从模板复制改造）
pixelwork/fx/fx-<name>/                   # 交付包目录（全新，绝不覆盖）
```

每个包内含：`frames/*.png`、`sprite-sheet.png`、`contact-sheet-8x.png`、
`atlas.json`、`palette.json`、`manifest.sha256`。

帧命名 `<clip>_<i>.png`（如 `impact_0.png`），查看器按前缀自动拆动作。

## 6. 目检（强制，不可跳过）

生成后**必须用 Read 工具打开 `contact-sheet-8x.png` 真实看图**，逐帧检查：

1. 轮廓：主体有没有描边、叠在深色背景上是否看得清
2. 帧间推进：是不是真的在"膨胀 / 上升 / 消散"，而不是简单缩放
3. 不截断：4 条边有没有被切掉的粒子
4. 亮度层次：back 淡 → body 主 → fx 亮，三层是否拉得开

发现一处问题就改参数重跑到**新目录**（加后缀 `-r2`、`-r3`，绝不覆盖旧包），最多迭代 3 轮。
最后用 `sha256sum -c manifest.sha256` 复核包完整性。
