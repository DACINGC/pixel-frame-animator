# 史莱姆王（King Slime）BOSS —— 设定文档

> 本文档是 `pixelwork/monsters/slime-king/` 工程的设定源头：先定角色与规格，再定动作与效果，最后才由 `gen_slime_king.py` 程序化生成帧包。
> 遵循 `pixelwork/monsters/CONTRACT.md` 全部硬约定；6 动作 22 帧 3 包是 BOSS 对小怪「4 动作 14 帧 2 包」配额的显式扩展（见 §7 兼容性说明）。

---

## 1. 角色背景与性格

**凝胶王国的君主**。比普通史莱姆（`monsters/slime/`）大上两号的深绿果冻体：底宽 26px、体高 16px、连同皇冠总高约 20px，坐在 FOOT_Y=27 接地线上，面朝左。

性格傲慢又憨厚：平时只是缓慢蹦跳巡视巢穴（move），被挑衅会挨打后硬扛（hit）、甩出伪足还击（attack）；真正惹怒它才会仰天咆哮、震慑来敌（roar），或者从嘴里吐出子嗣群殴（summon）。倒下时不散成一滩普通水渍，而是留下一顶卧在水渍旁的金冠——王者最后的尊严（death）。

与普通史莱姆的同系关系：同色系但更深沉的主体绿、同款果冻体质（白泽光/深绿内核/伪足/水渍死亡），加上王者三件套——**锯齿金冠、红宝石、深紫披风**。

### 3.2 remap（状态染色）

- **flash（受击闪白）**：`{1:8, 2:5, 3:5, 4:5, 6:5, 8:5, 9:5, 11:10, 13:5, 14:5, 15:5}`，眼睛强制横线。身体/披风/宝石/内核转白，描边转红，**皇冠 11→10 保持金色**——闪白帧仍认得出是王。
- **tint（受击暗红）**：`{1:7, 4:15, 13:14, 14:15}`。描边转暗红、身体暗部与披风暗部转暗红，金冠不变。

### 3.3 锚点与几何（写死，姿态只做相对偏移）

| 常量 | 值 | 说明 |
|---|---|---|
| SIZE | 32 | 契约固定 |
| CX | 15 | 比小怪左移 1px，给右侧披风让位 |
| TOP_Y | 12 | 中立头顶（皇冠再高 4px，冠顶 y=8） |
| BASE_Y / FOOT_Y | 27 | 与小怪同一接地线 |
| HALF_W | 13 | 底宽 26px |
| DOME_H | 16 | 中立体高 16 行 |

`body_shape`：`h=DOME_H-squash`（clamp[5,20]）、`hw=HALF_W+round(squash*0.6)`（clamp[5,14]）。
`body_mask`：半圆顶+平底，wobble 只甩上半部，底部不动（同蓝本）。

**安全值域**：`dy∈[-4,+2]`、`lean∈[-2,+3]`、`squash∈[-3,+4]`、`wobble∈[-2,+2]`、`swing∈[-2,+2]`、`reach∈[0,5]`、`eyeoff∈[-1,+1]`。

**三条铁律**（违反即出界，脚本内有断言兜底）：
1. 宽帧禁负 lean：`squash≥+1` 时 lean 只能 0/+1；
2. `cx+hw=30` 的帧禁正 swing（披风右缘 ≤30）；
3. 伪足尖端 `tip=cx-hw-reach≥2`（冲击星才有展开空间）。

## 7. 交付结构与兼容性说明

```
pixelwork/monsters/slime-king/
├── DESIGN.md / gen_slime_king.py
├── slime-king-move-hit/        # move_0..3 + hit_0..1（6 帧）
├── slime-king-attack-death/    # attack_0..3 + death_0..3（8 帧）
└── slime-king-roar-summon/     # roar_0..3 + summon_0..3（8 帧）
```

每个包内固定 6 件套：`frames/`、`sprite-sheet.png`、`contact-sheet-8x.png`、`atlas.json`、`palette.json`、`manifest.sha256`。atlas.json 的 schema 与字段顺序同小怪先例，仅 `pack/actions/frames` 取值不同——viewer 等图集工具零改动可直接读；6 动作 3 包是对 CONTRACT「4 动作 2 包」小怪配额的 BOSS 显式扩展（每包仍 ≤8 帧），记录于此备查。迭代规则：不合格跑 `-r2/-r3` 新目录，绝不覆盖旧包。
